# Agent instructions (Codex)

This repo is worked on by both Codex and Claude. The rules are shared and live in one place:

1. **Read `CLAUDE.md`** — project overview, working rules, quality gates, layout and test commands. Its rules apply to every agent, not just Claude. Ignore its "Tools in this setup" section (Claude-specific).
2. **Read `docs/Progress.md` before doing anything and update it before you stop.** It says where the work is, what the current task is, and what the last agent left half-done. Follow its rules exactly.
3. **`docs/Design.md`** is the design source of truth. Read the sections the current task names.

Do only the current task in `docs/Progress.md`. Do not commit unless the user asks.
